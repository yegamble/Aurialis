## Rules

- Every task: RED test → GREEN impl → `pnpm exec tsc --noEmit && pnpm lint && pnpm vitest run`
  green → one atomic commit. Playwright suites run at stage gates (not every commit).
- Preserve every existing `data-testid` contract; update specs in the same commit as any
  DOM change that must move one.
- Design fidelity never trumps truth: no fake labels (no "Mid/Side" caption unless the
  waveform actually renders M/S), no dead buttons, no mocked numbers presented as real.
- Prototype conceits stay out: WindowChrome traffic lights (removed in 3651daa — settled),
  mock BPM/key/artist metadata, sine-wave sim meters.
